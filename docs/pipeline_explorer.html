阶段三：去噪大脑怎么猜出被遮住的音符？（真实模型探针）

网络把 4 路提示信息相加，经 3 层**双向注意力**同时看左看右，最后在每个位置输出 40 个符号的预测概率。

1. 词元嵌入 `tok_emb`
认出没被遮住的邻居音符是什么（如第 0 格是 `14 = C4`）。
2. 全局位置 `pos_emb`
定位 `0..63` 处于第几小节（开头起调还是末尾收束）。
3. 拍点位置 `pos % 8`
标出 2/4 拍内强弱拍位置（奇数弱分拍极易是 `HOLD` 延长）。
4. 噪声步长 `time_mlp(t)`
用正弦编码告诉网络现在有多模糊（当前 `t = 25`）。
实测案例：《天上黄河几道湾》`t=25` 时被遮住的第 1 格（前1格=C4, 后1格=D4, 真值=`1 HOLD`） 真实加载 `best_model.pt` 计算结果

可以看到：虽然第 1 格被遮成 `?`，双向网络结合前一位 `1 (C4)`、后一位 `2 (D4)` 以及 `pos % 8 = 1` 的弱拍规律，以 **63.6%** 的最高概率精准猜出它应当是 `HOLD (1)`，而且其余备选音高全部落在五声音阶 `{1, 2, 3, 5, 6,}` 内！
